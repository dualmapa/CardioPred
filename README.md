
# CardioPred: Sistema de Soporte Clínico

App en **Streamlit** para estimar riesgo de enfermedad cardíaca usando IA.

## Cómo probar
- Instala dependencias: `pip install -r requirements.txt`
- Ejecuta: `streamlit run app.py`

## Nota
Este sistema es un **CDSS** (Clinical Decision Support System), no sustituye el juicio médico.
